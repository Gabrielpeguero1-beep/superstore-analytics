# Superstore Analytics 📊

Proyecto de análisis de datos end-to-end utilizando 
el dataset Sample Superstore de Kaggle.

## 🛠️ Stack tecnológico
- **SQL Server** — Modelado relacional y limpieza de datos
- **Python** — Análisis exploratorio y modelo predictivo
- **Power BI** — Dashboard interactivo profesional

## 📥 Dataset
Descarga el dataset desde:
https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

Coloca el archivo CSV en la carpeta `/data` antes 
de ejecutar los scripts SQL.

## 🔍 Hallazgos principales
- El **18.7%** de las transacciones generan pérdidas
- Umbral crítico de descuento identificado en **20%**
- **Furniture** es la categoría menos rentable (2.48%)
- **West** es la región más rentable ($108,404)
- Modelo Random Forest: **94% accuracy** y 
  **88% recall** en detección de pérdidas
- El descuento explica el **64%** del poder predictivo
